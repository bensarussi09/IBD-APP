# IBD FOOD Project

## Overview
IBD FOOD is a web application designed to help users manage meals, recipes, study sessions, and daily nutrition tracking in a simple and user-friendly interface.

The application was developed using React and Supabase as part of a web development academic project.

## Features

### User Authentication
- User registration
- User login
- Secure authentication using Supabase

### Meal Management
- Add meals
- Edit meals
- Delete meals
- Save meal history

### Recipes
- Browse recipes
- Save favorite recipes
- Rate recipes

### Weekly Planning
- Create a weekly meal plan
- Organize meals by day

### Study Sessions
- Create study sessions
- Track study activities
- Store study session history

### Feedback System
- In-app feedback widget
- Feedback stored in Supabase
- User-specific feedback access using RLS policies

### Monitoring & Analytics
- Microsoft Clarity integration
- Sentry error monitoring

## Technologies Used

- React
- JavaScript
- CSS
- Supabase
- Netlify
- Microsoft Clarity
- Sentry
- GitHub

## Database Tables

### profiles
Stores user profile information.

### study_sessions
Stores study session data.

### tasks
Stores user task information.

### feedback
Stores user feedback submitted through the application.

## Deployment

The application is deployed using Netlify.
